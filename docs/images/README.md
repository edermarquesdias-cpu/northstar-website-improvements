# Screenshot Assets

Upload the final NorthStar Home Services comparison screenshots to this folder using these exact filenames:

- `before-desktop.webp` — representative desktop state before improvements
- `after-desktop.webp` — matching desktop state after improvements
- `before-mobile.webp` — representative mobile state before improvements
- `after-mobile.webp` — matching mobile state after improvements
- `responsive-fixes.webp` — responsive behavior or breakpoint correction evidence
- `ui-improvements.webp` — representative UI/UX refinement evidence

## Presentation Rules

- Use matching Before/After views whenever possible.
- Keep viewport dimensions comparable between each pair.
- Avoid unrelated browser chrome, personal data or sensitive customer information.
- Prioritize screenshots where the improvement is immediately visible.
- Do not over-edit the Before image; it should accurately represent the original state.
